mcp-code-editor

Connect the AI agent of your web chat to the project on your computer. A Windows app that runs a local MCP server and exposes it through an OAuth-protected tunnel, so the agent of ChatGPT — or any client that accepts custom MCP servers — can read, search, edit, build and test your project on disk, including the text of Word and PDF documents. Every command needs your approval; secret files stay hidden.
