mcp-code-editor

Connect the AI agent from your web chat to the project on your computer.

mcp-code-editor is a free Windows desktop application. It runs a local MCP (Model Context Protocol) server for one project folder and publishes it through a Cloudflare tunnel protected by OAuth 2.1 with PKCE. Paste the endpoint into ChatGPT (developer-mode connectors) or any client that accepts custom MCP servers, and the agent works on your real project: no more copy-paste between the chat and your editor, no API key — your chat subscription is enough.

What the agent can do

  • Read, list and search the whole project; view screenshots and diagrams; read the text of Word and PDF documents.
  • Edit files precisely, create and delete files — in Read-Write mode.
  • Build and test .NET projects, run other commands after your approval.
  • Navigate like an IDE: compiler diagnostics, go-to-definition, find references (C#, Python, JavaScript/TypeScript, HTML, CSS).

You stay in control

  • Every command is shown to you for approval (default).
  • Secret files (.env, keys, certificates) are hidden from the agent; .gitignore is respected.
  • Every change is written to an audit log; Read-Only mode for projects you do not trust.
  • The server listens only on 127.0.0.1; it is reachable only through the tunnel, while the app runs, after sign-in.
