UiGuide Agent

Your users ask. Your app answers. No documentation to write.

UiGuide Agent is an AI help agent you add to any application with a user interface. Your users ask “how do I…?” inside your app and get concrete steps — which button to press, what happens next — in their language, starting from the screen they are on.

Why

  • No help pages to write: it learns your application from your source code — windows, controls, texts, which button opens which screen — automatically, at every build.
  • Never out of date: change the UI, rebuild, and the answers follow the new version.
  • The exact buttons, in the user's language: the answer follows the language of the question and names every button exactly as it appears on screen — also when the user switches the application's language.
  • Starts where the user is: it sees the current screen and skips the steps already done.
  • Minutes to add: one NuGet package (WPF, WinForms, Blazor) or one npm package and one line in your bundler's configuration — no code. Applications you cannot change are covered by the Companion.
  • Your LLM, your server, your data: any OpenAI-compatible endpoint (LiteLLM, vLLM, Ollama, OpenAI); besides the question, only UI structure and labels leave the app — never the values in fields, never passwords.
  • Safe answers: the assistant never gives links, downloads or commands, never asks for passwords, codes or card details, and ignores instructions hidden in texts shown by your application.

The server

One server for all your applications: a .NET tool on your computer for testing, then your company's — Docker image ghcr.io/domitorai/ui-guide-agent-server or a Windows service. If it cannot use your LLM, it tells you why: no key, a refused key, a model the key cannot use, a wrong address.
